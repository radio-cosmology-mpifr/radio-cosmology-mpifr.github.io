# Radio Cosmology @MPIfR

This is the repo of the Radio Cosmology research group at the Max Planck Institute for Radio Astronomy in Bonn, led by Prof Jonathan Pritchard.

The group's current work focusses on applications of radio astronomy to cosmology, especially preparing for observations with the Square Kilometre Array and the use of machine learning for handling large data sets.
